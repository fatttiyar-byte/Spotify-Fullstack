## 📖 Overview

**Spotify Clone** is a production-ready, full-stack web application that replicates the core experience of Spotify — from browsing tracks and creating playlists to streaming audio with a persistent, interactive player.

Built on the **MERN stack** (MongoDB, Express, React, Node.js) and styled with **Tailwind CSS**, this project showcases a complete modern web development workflow: REST API design, JWT authentication, media storage, global state management, and a responsive, pixel-perfect UI.

> 🎯 **Goal:** Deliver a real-world, portfolio-grade application that demonstrates end-to-end full-stack engineering skills.

---

## ✨ Features

### 🎧 Core Experience
- **Music Streaming** — Play, pause, skip, seek, and control volume
- **Persistent Player** — Bottom bar that survives route changes
- **Playlists** — Create, edit, reorder, and delete playlists
- **Like System** — Save favorite tracks to your library
- **Search** — Find songs, artists, and albums instantly
- **Queue Management** — Add tracks to a play-next queue

### 🔐 Platform & UX
- **JWT Authentication** — Secure register/login flow
- **Protected Routes** — Client + server-side guards
- **Responsive Design** — Mobile-first, fluid on all screens
- **Dark Theme** — Signature Spotify-inspired aesthetic
- **Cloud Uploads** — Audio & artwork via Cloudinary
- **Optimistic UI** — Instant feedback on user actions

## 🛠️ Tech Stack

| | MongoDB + Mongoose | NoSQL database & schema modeling |

| | Postman | API testing |
| | MongoDB Atlas | Cloud database |
| | Vercel + Render | Deployment targets |
